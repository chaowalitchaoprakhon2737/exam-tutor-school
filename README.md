# ระบบติวข้อสอบ ครู-นักเรียน

เว็บ Node.js + Express แบบแยกหน้าครูและนักเรียน พร้อม deploy บน Render

## ความสามารถ
- ครูสร้างข้อสอบ 1-200 ข้อ กำหนด 2-6 ตัวเลือกและเฉลย
- ครูกำหนดเวลา 1-300 นาที
- นักเรียนเข้าใช้งานด้วยเลขประจำตัวและชื่อ
- ตอบทีละข้อ ย้อนกลับหรือแก้ไขไม่ได้
- หลังเลือก ระบบแสดงทันทีว่าถูกหรือผิด พร้อมเฉลย
- ครูเห็นคะแนนและคำตอบรายข้อของนักเรียน

## ทดลองบนเครื่อง
1. ติดตั้ง Node.js 20+
2. คัดลอก `.env.example` เป็น `.env` (ถ้าใช้ shell ให้ export ตัวแปรเอง)
3. รัน `npm install`
4. รัน `TEACHER_PIN=รหัสของคุณ npm start`
5. เปิด http://localhost:3000

รหัสครูเริ่มต้นสำหรับทดลองคือ `1234` แต่ต้องเปลี่ยนก่อนใช้งานจริง

## Deploy บน Render
1. แตก ZIP แล้วนำโฟลเดอร์ขึ้น GitHub repository
2. ใน Render เลือก New > Blueprint และเชื่อม repository
3. Render จะอ่าน `render.yaml`
4. ตั้งค่า secret `TEACHER_PIN`
5. กด Apply และรอ URL `onrender.com`

โปรเจกต์ตั้งค่า persistent disk ที่ `/var/data` ไว้แล้วเพื่อเก็บข้อสอบและผลนักเรียน การใช้ disk ต้องเลือกแผนที่รองรับ persistent disk

## หมายเหตุการใช้งานจริง
- รุ่นนี้เหมาะกับห้องเรียนหรือการติวขนาดเล็ก และมีครูผู้ดูแลหนึ่งรหัส
- เก็บข้อมูลเป็น JSON file จึงไม่เหมาะกับผู้ใช้พร้อมกันจำนวนมาก หากเกินประมาณ 50-100 คนพร้อมกัน ควรย้ายไป PostgreSQL
- ควรแจ้งวัตถุประสงค์การเก็บเลขประจำตัวและชื่อนักเรียน กำหนดระยะเวลาเก็บ และจำกัดผู้เข้าถึงผลคะแนน


## URL แยกตามบทบาท
- นักเรียน: `/student.html`
- ครู: `/teacher.html` (ต้องใช้ TEACHER_PIN)
- หน้าเลือกบทบาท: `/`

เฉลยทั้งหมดไม่ถูกส่งไปยัง Browser ของนักเรียนล่วงหน้า Server จะส่งเฉลยของข้อนั้นกลับมาหลังบันทึกคำตอบแล้วเท่านั้น
