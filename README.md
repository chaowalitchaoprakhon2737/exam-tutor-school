# Exam Tutor Live

ระบบติวข้อสอบแบบครูปล่อยทีละข้อ นักเรียนตอบแล้วเห็นเฉลยทันที พร้อม feedback และ confetti

## ติดตั้ง
1. Supabase > SQL Editor: รัน `supabase.sql` ทั้งไฟล์ (สคริปต์นี้ล้างตารางข้อสอบเดิม)
2. ตรวจ `config.js`
3. แทนไฟล์ใน GitHub repository แล้ว push เข้า main
4. ครูเข้าหน้า `teacher.html` สร้างชุดข้อสอบหนึ่งครั้ง
5. แท็บควบคุมการติว > เริ่มรอบใหม่ > ส่งข้อ 1 > ส่งข้อถัดไป

## ฟังก์ชัน
- ครูสร้างข้อสอบครั้งเดียวและใช้เปิดรอบใหม่ได้
- นักเรียนเห็นเฉพาะข้อปัจจุบัน
- ตอบได้ครั้งเดียว พร้อมเฉลยหลังตอบ
- Feedback ถูก/ผิด พร้อม animation
- ครูเห็นสถิติข้อปัจจุบันแบบ polling ทุก 2.5 วินาที
- รีเซ็ตคะแนนรายคนหรือเคลียร์ทั้งห้อง
